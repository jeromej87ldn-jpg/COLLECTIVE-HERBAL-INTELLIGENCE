TECHNICAL SPECIFICATIONS
================================================================================

HERBADEX_MASTER_FINAL.json Structure:
{
  "metadata": {
    "version": "1.0.0",
    "total_herbs": 178,
    "api_ready": true
  },
  "herbs": [
    {
      "id": 1,
      "name": "Ginger",
      "latin": "Zingiber officinale",
      "search_key": "ginger_zingiber officinale",
      "status": "insufficient_data"
    },
    ...
  ]
}

Status Values:
• insufficient_data - Ready for profile generation
• pending_verification - Partial data loaded
• verified - Full profile complete

Search Key Format:
"{lowercased_name}_{first_two_words_of_latin}"
Example: "Japanese Knotweed" + "Fallopia japonica"
         → "japanese knotweed_fallopia japonica"
